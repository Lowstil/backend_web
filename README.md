# Лабораторная работа: Решение заданий (Backend Web)

В данном репозитории реализованы решения двух заданий по переводу структуры данных в объектную модель (ООП) и валидации бизнес-логики записи клиентов салона.

---

## 📌 Содержание заданий

### Задание 1. Класс `Appointment` (`Appoinment`)
* **Цель:** Перевести структуру `appointment` из обычного словаря в полноценный класс.
* **Требование:** Функция `create_appointment` должна возвращать объект класса `Appointment`. Объект создаётся **только** в том случае, если заполнены все поля (`client_name`, `master_id`, `service_id`, `time`). Если какое-либо поле пустое или невалидное, функция возвращает `None`, а запись не добавляется в общий список `appointments`.
* **Поддержка наименований:** В коде реализован класс `Appointment`, а также алиас `Appoinment = Appointment` для полной совместимости с опечаткой из текста задания.

### Задание 2. Новое бизнес-правило (Часы работы салона)
* **Цель:** Ограничить время записи клиентов рабочими часами салона.
* **Требование:** Записаться к мастеру можно **только с 08:00 до 20:00**. Время вне этого диапазона (например, `'00:00'`, `'07:59'`, `'20:01'`) отклоняется: функция возвращает `None`, и запись не попадает в список `appointments`.

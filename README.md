# Лабораторная работа: Backend Web (Beauty Salon API)

В данном репозитории реализованы практические задания по разработке бэкенда для салона красоты:
1. **Объектно-ориентированная модель и бизнес-логика записи клиентов** (Задания 1 и 2).
2. **REST API эндпоинты категорий услуг на FastAPI** (Задания: Список категорий и Информация по категории).

---

## 📌 Содержание заданий

### Часть 1. Запись клиентов (ООП и бизнес-правила)

* **Задание 1. Класс `Appointment` (`Appoinment`)**
  * Структура `appointment` переведена из словаря в объект класса `Appointment`.
  * Функция `create_appointment` возвращает экземпляр `Appointment` только при условии, что заполнены все обязательные поля. При неполных данных возвращается `None`, и запись не добавляется в `appointments`.
  * Реализован алиас `Appoinment = Appointment` для совместимости с формулировкой задания.

* **Задание 2. Часы работы салона**
  * Добавлено бизнес-правило: записаться к мастеру можно **только с 08:00 до 20:00**.
  * Запись на некорректное время (например, `'00:00'`, `'07:59'`, `'20:01'`) отклоняется (`None`).

---

### Часть 2. Реализация REST API Эндпоинтов (FastAPI)

* **Задание 1. Список категорий (`GET /categories`)**
  * Возвращает список всех категорий услуг со статус-кодом **200 OK**.
  * Каждая категория содержит: `id`, `name`, `servicesCount`.
  * **Пример ответа (200 OK):**
    ```json
    [
      { "id": 1, "name": "Стрижки и укладки", "servicesCount": 5 },
      { "id": 2, "name": "Маникюр и педикюр", "servicesCount": 5 },
      { "id": 3, "name": "Брови и ресницы", "servicesCount": 4 },
      { "id": 4, "name": "Спа-процедуры", "servicesCount": 4 }
    ]
    ```

* **Задание 2. Информация по категории (`GET /categories/{category_id}`)**
  * Возвращает информацию о конкретной категории услуг по её идентификатору.
  * Если категория найдена — возвращает статус-код **200 OK** и объект категории:
    ```json
    { "id": 1, "name": "Стрижки и укладки", "servicesCount": 5 }
    ```
  * Если категория с указанным ID не найдена — возвращает статус-код **404 Not Found**:
    ```json
    { "detail": "Category not found" }
    ```

## 🚀 Запуск и проверка

### 1. Запуск демонстрации всех заданий:
```bash
python main.py
```

### 2. Запуск локального веб-сервера FastAPI (с интерактивной документацией):
```bash
uvicorn app:app --reload
# либо
python main.py --serve
```
После запуска доступны:
* Интерактивная документация Swagger UI: **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**
* Альтернативная документация ReDoc: **[http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)**

### 3. Запуск автоматических тестов:
```bash
python -m unittest discover tests
```
Все 11 тестов проходят успешно (`Ran 11 tests ... OK`).
